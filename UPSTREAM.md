# Upstream provenance

Night Dock is patwikx's customized launcher project, based on [partridgeworks/webos-launcher](https://github.com/partridgeworks/webos-launcher).

The source snapshot used for this work descends from upstream commit `1e2c39b`. The upstream commit history is retained in this repository. The `upstream` Git remote points to the original repository; the `origin` remote points to Patrick's private Night Dock repository.

The upstream code is licensed under the MIT License. Its original copyright notice remains in `LICENSE`, followed by credit for patwikx's modifications. Third-party software and artwork are listed separately in `THIRD_PARTY_NOTICES.md`.

`README.upstream.md` preserves the original project documentation as historical reference. The main `README.md`, `PRODUCT.md`, and `DESIGN.md` describe the current launcher. `LOCAL-REDESIGN.md` records the earlier Apple TV inspired iteration and is also historical.

The Night Dock changes include the dock interface, night-lake/glass visual treatment, Sources dropdown, tabbed Settings redesign, selection styling, YouTube focus artwork, Home-only animations, and runtime/startup optimizations. Existing Luna services, catalogue behavior, storage format, and other upstream code remain part of the project.
