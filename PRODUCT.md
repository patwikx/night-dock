# Product

The owner of an LG 55UT8050PSB uses a remote or Magic Remote pointer to launch installed apps and switch inputs from the sofa. The TV is rooted, runs webOS 10.3.2, and renders this app at 1920 × 1080.

This update adapts the user's Night Dock reference from `/tmp/opencode` and the prior `launcher-design-review` folder. Preserve the app ID, saved app/source selections, clock format, app launching, input switching, remote Back, pointer control, and existing system startup/Home integration. Changes to system startup, memory policy, or key mappings are outside this visual update.

Settings must offer all discoverable apps and inputs, hiding/showing and reordering apps, and the existing opt-in Homebrew app-list option. The app must package local assets and run without a network-hosted UI.
